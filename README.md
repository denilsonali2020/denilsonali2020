## Featured project

### Petite Amelie POS

A personal project: a point-of-sale and e-commerce system for a cosmetics store. Currently in development.

**What it does**
- Product categorization and catalog management
- Customer and user management
- In-store sales and home delivery through a shipping company

**How it is built**

- **Frontend:** React with TypeScript, screaming architecture
